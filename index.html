The practice

// how the systems get built
/01 — architecture

Kernel-first systems

Small trusted cores — registry, capability contracts, lifecycle, audit — with everything else a plugin behind defined interfaces. Extensibility without entropy. The same pattern runs my platforms and my agent infrastructure.

/02 — agentic

AI does the volume. Humans hold the boundary.

LLMs working together autonomously — properly: shared memory, scoped permissions, declared files, evidence before done. Kernel and security paths stay human-reviewed. The git history is the workflow; the audit trail is the proof.

/03 — evidence

Receipts, not adjectives

Migrations with every schema change. Tamper-evident audit chains on privileged actions. Launch tests against the running system — never static analysis alone. A task isn't done until production proves it.
