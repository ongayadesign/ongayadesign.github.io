How the work gets built

// three operating principles
/01 — kernel-first

Small trusted core, everything else a plugin

Platforms start from a minimal kernel — registry, capability contracts, lifecycle, audit — and grow through plugins that can only reach the outside world through defined interfaces. Extensibility without entropy.

/02 — audit-grade

Evidence before "done"

Schema changes ship with migrations. Privileged actions emit tamper-evident audit events. Launch tests, not static analysis. A task isn't finished until the running system proves it.

/03 — agentic

LLM-orchestrated development

AI agents do the volume — scoped to single plugins, single files, declared permissions — while humans hold the review boundary on kernel and security paths. The git history is the workflow.
